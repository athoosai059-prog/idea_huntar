## 🛠️ Troubleshooting

### If UI Doesn't Load
1. **Check Server**: Ensure Flask server is running on port 5000
2. **Clear Cache**: Clear browser cache and reload
3. **Check Console**: Open browser developer tools (F12) for errors
4. **Verify API**: Test API endpoints using verification.html

### If Ideas Don't Load
1. **Check Database**: Ensure SQLite database has data
2. **Run Pipeline**: Execute the discovery pipeline
3. **Refresh Data**: Click the Refresh button
4. **Check Logs**: Review server logs for errors

### If Features Don't Work
1. **Test API**: Use debug.html to test API endpoints
2. **Check Settings**: Verify API keys and configuration
3. **Restart Server**: Stop and restart the Flask server
4. **Review Logs**: Check for error messages
